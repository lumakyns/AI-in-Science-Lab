Test whether calibrating one output-to-input recurrence enables supervised MNIST classification: a bias-free linear 784-128-64-32-10 network learns one-hot labels using half summed squared error and SGD. Compare BP, fixed random feedback, damped forward-probe calibration R=V Y^T(YY^T+lambda I)^-1, and calibrated feedback with an orthogonal output scramble. Scrambling preserves bridge rank and singular values at fixed weights while changing error orientation. All methods use matched initialization, data order, learning-rate grids, and seeds. Rank is a diagnostic, never an objective.

Log classification loss/accuracy and frozen-weight held-out audits of BP versus recirculated error matrices: numerical/effective rank, cosine, norm ratio, sign agreement, and hidden-only aggregate parameter-gradient alignment. Calibrated modes refresh every 100 updates with 16 orthonormal input probes; the linear model measures exact directional responses using forward passes alone. Compare probe conditioning, forward-probe budget, failures, held-out accuracy, and wall time. BP audit calculations do not contribute to approximate training updates. No autoencoder reconstruction, tied weights, or hidden activations are used in this first controlled experiment.
