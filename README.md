# AI in Science Lab

A research repository for independent machine-learning experiments.

- `src/`: experiment code, configuration, models, and design notes.
- `data/`: dataset preparation and local datasets.
- `checkpoints/`: generated model weights, metrics, figures, and tracking files.
- `archive/`: historical code, research notes, and disabled automation.
- `setup.sh`: environment setup.
- `AGENTS.md`: repository conventions for coding agents.

Dataset contents and generated run artifacts are excluded from version control.
